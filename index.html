กดสร้างรัว ๆ ก็ไม่มีกระตุก เพราะนี่คือ Barcodedzy. ระบบรีดประสิทธิภาพลาเบลสินค้าแบบ Single-File ส่งออกรูปภาพ PNG/JPG คมชัดทันใจ เลย์เอาต์ 3 บรรทัดกึ่งกลางเป๊ะทุกพิกเซล พร้อมเคลียร์พื้นหลังและเว้นระยะ Margin บาร์โค้ดขั้นเทพ ยิงมุมไหนก็ติด

เริ่มตรงนี้: เลือกวิธีสร้าง Label → กรอกข้อมูลสินค้า → ดู Preview ด้านขวา → Export
เลือกวิธีสร้าง Label

เลือกสร้าง Label ใบเดียวสำหรับงานเร็ว หรือสร้างหลายใบแบบวางข้อมูลแยกตามช่อง แล้ว Export เป็น ZIP / Print Sheet

ข้อมูลสินค้า
ข้อมูล GTIN / Barcode

ถ้าช่องนี้ว่าง ระบบจะสร้าง ITF-14 จาก GTIN-13 + Level ให้อัตโนมัติ แต่ถ้าบริษัทมีเลข GTIN Lv3/Lv4 จริงอยู่แล้ว ให้ใส่เลข 14 หลักในช่องนี้เพื่อให้ Preview ตรงระบบ

ข้อมูลตาราง
โหมด EAN-13 — กรอกเฉพาะ GTIN-13 / EAN-13 ใส่ 12 หลัก ระบบจะคำนวณ check digit ให้ หรือใส่ 13 หลัก ระบบจะ validate ให้ ผลลัพธ์จะเป็น label ขนาด 70 × 20 mm มีเฉพาะ barcode และเลขข้างล่าง
ข้อมูลหลายรายการแบบแยกช่อง

วางข้อมูลจาก Excel / Google Sheets ทีละคอลัมน์ได้เลย ระบบจะจับคู่ตามลำดับบรรทัด ถ้าช่องไหนมีค่าเดียวจะใช้ค่านั้นกับทุกใบ ถ้าช่องไหนว่างจะใช้ค่าจากฟอร์มใบเดียว

1. ชื่อสินค้า

2. Barcode

3. จำนวนและตาราง

โหมด EAN-13 (Batch) — กรอกเฉพาะ GTIN-13 / EAN-13 หลายรายการ ระบบจะคำนวณ check digit ให้อัตโนมัติเมื่อใส่ 12 หลัก หรือ validate เมื่อใส่ 13 หลัก ผลลัพธ์ทุกใบจะเป็น label ขนาด 70 × 20 mm

4. จัดหน้าสำหรับพิมพ์

Print Sheet จะจัดเฉพาะชุดที่กำลังดู และใช้ browser print / Save as PDF เหมือน workflow เดิม กรุณาตั้ง Scale เป็น 100% หรือ Actual Size

ยังไม่ได้ใส่ข้อมูลหลายรายการ

ระบบจะแสดงและ Export ทีละชุด ชุดละ 10 รายการ เพื่อลดอาการหน่วงเวลาใช้งานจริง

Privacy note: เว็บไซต์นี้อาจเก็บข้อมูลการใช้งานแบบไม่ระบุตัวตนเพื่อปรับปรุงประสิทธิภาพและประสบการณ์การใช้งาน เมื่อเปิดใช้ Cloudflare Web Analytics หรือ Plausible ในอนาคต
