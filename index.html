ITF-14 Label Generator

แบบไฟล์เดียวจบ ไม่แยก CSS/JS และ Preview เป็น Label เต็มใบตาม SVG layout เดิม: ชื่อสินค้า, ชื่ออังกฤษ, ชื่อไทย, GTIN ด้านบน, ITF-14, LOCATION, QTY, G.W. และ LOT NO. เพิ่ม Export SVG แบบ Vector จริง ไม่ฝังภาพ raster, เอาพื้นหลังขาวหลังบาร์โค้ดออก, จัดชื่อสินค้า 3 บรรทัดให้อยู่กึ่งกลาง และเว้นระยะขอบซ้าย-ขวาของแท่งบาร์โค้ดเพื่อให้สแกนได้ง่ายขึ้น

เริ่มตรงนี้: กรอกข้อมูลสินค้า → เลือก GTIN Level → ดู Preview ด้านขวา
ข้อมูลสินค้า
ข้อมูล GTIN / Barcode

ถ้าช่องนี้ว่าง ระบบจะสร้าง ITF-14 จาก GTIN-13 + Level ให้อัตโนมัติ แต่ถ้าบริษัทมีเลข GTIN Lv3/Lv4 จริงอยู่แล้ว ให้ใส่เลข 14 หลักในช่องนี้เพื่อให้ Preview ตรงระบบ
